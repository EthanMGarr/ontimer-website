# Current Campaign

This file contains active strategic work. It is intentionally temporary and should change more often than the rest of BrandOS.

## Current Objective

Make OnTimer's public positioning clearer around one promise: OnTimer automatically keeps you on time.

## Current Positioning

Outcome: stay on time.

Mechanism: automatic calendar alarms from the user's existing calendar.

Proof: Google Calendar, Microsoft Outlook, persistent alarms, Time To Leave, and multiple calendars.

Primary customer-facing hero message: "Never be late again."

## Current ASO Direction

Continue treating "calendar alarm app" as the leading category hypothesis.

Support with meeting alarm, appointment alarm, Time To Leave, and calendar-notification alternatives where they match user intent.

Do not finalize ASO changes until live rank, search result, screenshot, pricing, and review-count gaps are verified.

## Current Screenshot Direction

Lead with the outcome before the feature.

Show automatic setup from the calendar, then prove the alarm behavior:

- Connect calendar once.
- Alarms are created automatically.
- Persistent alarm fires before the moment to act.
- Time To Leave supports location-based events.

Avoid screenshots that look like generic planner, calendar, or reminder-app messaging.

## Current Open Questions

- Should "Never be late again" replace the current homepage hero headline?
- How directly should screenshots say "automatically keeps you on time"?
- Which ASO cluster has the strongest live rank opportunity: calendar alarm, meeting alarm, or appointment alarm?
- How much should Time To Leave appear in primary positioning versus secondary proof?
- How should ADHD and time blindness language be used without overclaiming?

## Current Experiments

- Test outcome-led messaging before mechanism-led messaging.
- Test "Never be late again" as the primary hero message.
- Test screenshot sequences that show automatic calendar connection before persistent alarm proof.
- Test category language around "calendar alarm app" while keeping "stay on time" as the outcome.
