# OnTimer ASO Research Database

Research date: 2026-06-26  
Market: United States Apple App Store unless stated otherwise  
Objective: determine the highest-opportunity keyword cluster OnTimer can realistically own.

## Files

| Phase | File | Output |
|---|---|---|
| 1 | [Phase01_Keyword_Universe.md](Phase01_Keyword_Universe.md) | Keyword universe grouped by user intent |
| 2 | [Phase02_Competitor_Database.md](Phase02_Competitor_Database.md) | Competitor facts and App Store metadata |
| 3 | [Phase03_Keyword_Clusters.md](Phase03_Keyword_Clusters.md) | Positioning analysis by competitor and cluster |
| 4 | [Phase04_Screenshot_Analysis.md](Phase04_Screenshot_Analysis.md) | Screenshot messaging patterns and gaps |

| 7 | [Phase07_Final_Findings.md](Phase07_Final_Findings.md) | Research findings and remaining unknowns |

## Research Rules Applied

| Rule | Implementation |
|---|---|
| Never assume | Unknown fields are marked `Needs human verification` instead of invented. |
| Cite every source | App facts link to source URLs in each report. |
| Distinguish facts from opinions | Tables separate `Verified facts` from `Analyst interpretation`. |
| Create human tasks when insufficient | Manual App Store search, screenshot transcription, and keyword rank capture tasks are listed in Phase 6. |
| Prefer structured tables | Every phase is table-first. |
| Every phase produces a report | All seven phase files are included. |
